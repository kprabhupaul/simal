LIGHTWEIGHT · DEPENDENCY-FREE · NATIVE DIALOG

Simple dialogs.
Without the overhead.

Simal is a lightweight JavaScript dialog library built on the native <dialog> element. Simple API, native forms, validation, lifecycle hooks, and browser/device Back-button support.

Get Started
✓ Zero dependencies ✓ Promise based ✓ Native validation ✓ Forms & inputs ✓ Back-button support
WHY SIMAL

Small API. Useful features.

Simal keeps the dialog experience simple while providing the features needed for everyday application dialogs.

◎

Native & lightweight

Built around the browser's native <dialog> element.

↗

Promise based

Handle confirm, cancel, and deny results with a simple Promise.

✓

Forms included

Use normal HTML inputs, forms, and native browser validation.

↩

Back-button aware

Browser and Android device Back can close the active dialog cleanly.

GETTING STARTED

Use Simal in seconds.

Add the stylesheet and script, then call simal.fire().

HTML
<link rel="stylesheet" href="simal.css">
<script src="simal.js"></script>
JAVASCRIPT
simal.fire({
    title: 'Welcome',
    text: 'Simal is working!',
    icon: 'success'
});

EXAMPLES

Explore the core features.

These examples use the actual Simal API.

01

Success dialog

simal.fire({
    title: 'Success!',
    text: 'Your changes were saved.',
    icon: 'success'
});
02

Confirm & cancel

const result = await simal.fire({
    title: 'Delete item?',
    text: 'This cannot be undone.',
    icon: 'warning',
    showCancelButton: true,
    confirmButtonText: 'Delete',
    cancelButtonText: 'Cancel'
});
03

Deny button

simal.fire({
    title: 'Choose an action',
    showDenyButton: true,
    showCancelButton: true,
    confirmButtonText: 'Save',
    denyButtonText: 'Discard',
    cancelButtonText: 'Cancel'
});
04

HTML content

simal.fire({
    title: 'HTML content',
    html: '<strong>Hello!</strong><br>This is HTML.'
});
05

Form & native validation

const result = await simal.fire({
    title: 'Create account',
    html: `
        <form>
            <input name="name" required
                   minlength="3"
                   placeholder="Your name">
            <input name="email" type="email"
                   required
                   placeholder="Email">
        </form>
    `,
    showCancelButton: true,
    preConfirm: (values) => values
});

console.log(result.value);
06

Validation message

preConfirm: async (values) => {
    if (values.name === 'admin') {
        simal.showValidationMessage(
            'That name is not allowed.'
        );
        return;
    }

    return values;
}
07

Lifecycle hooks

simal.fire({
    title: 'Lifecycle',
    text: 'Open the browser console.',
    preOpen: (dialog) => console.log('preOpen', dialog),
    didOpen: (dialog) => console.log('didOpen', dialog),
    preClose: (dialog) => console.log('preClose', dialog),
    didClose: (dialog) => console.log('didClose', dialog)
});
08

Pre-deny

simal.fire({
    title: 'Discard changes?',
    showDenyButton: true,
    preDeny: async () => {
        return 'discarded';
    }
});
CONFIGURATION

Everything in one place.

Pass an options object to simal.fire().

Parameter Default Description
icon '' Dialog icon. Supported values: success, error, warning, info, question.
title '' Dialog title.
text '' Plain text content.
html '' HTML content. Takes priority over text. You can also provide an element ID selector (e.g. #myContent) to move an existing HTML element into the dialog.
htmlDisplayToggleClass 'no_display' CSS class(es) removed from an existing HTML element while it is inside the dialog and restored when the dialog closes. Set to '' to disable.
position 'center' Dialog position. Supported values: top, top-start, top-end, center, center-start, center-end, bottom, bottom-start, bottom-end.
width — Custom dialog width (e.g. '500px', '80%').
height — Custom dialog height.
maxWidth — Maximum dialog width.
maxHeight — Maximum dialog height.
minWidth — Minimum dialog width.
minHeight — Minimum dialog height.
showCloseButton false Show the close (×) button in the dialog.
closeButtonHtml '×' HTML content displayed inside the close button.
closeButtonAriaLabel 'Close' Accessible label for the close button.
showConfirmButton true Show the Confirm button.
showCancelButton false Show the Cancel button.
showDenyButton false Show the Deny button.
confirmButtonText 'OK' Confirm button label.
cancelButtonText 'Cancel' Cancel button label.
denyButtonText 'Deny' Deny button label.
allowOutsideClick true Allow closing the dialog by clicking outside it.
allowEscapeKey true Allow closing the dialog by pressing the Escape key.
preConfirm null Runs before confirmation. Receives input values and supports synchronous or asynchronous functions. Returning false or undefined prevents the dialog from closing.
preDeny null Runs before denial. Receives input values and supports synchronous or asynchronous functions. Returning false prevents the dialog from closing.
preOpen null Runs after Simal's initial setup but before the dialog is displayed. Receives the dialog element.
didOpen null Runs after the dialog is displayed. Receives the dialog element.
preClose null Runs when the dialog's closing process starts. Receives the dialog element.
didClose null Runs after the dialog is closed, removed from the DOM, and the original HTML element (if any) is restored. Receives the dialog element.
customClass object Customize CSS classes for individual dialog elements, including the dialog, container, buttons, icons, title, content, validation message, inputs, form, and animations.
CUSTOM CLASSES
customClass: {
    dialog: 'simal-dialog',
    container: 'simal-container',
    icon: 'simal-icon',
    iconSymbol: 'simal-icon-symbol',
    title: 'simal-title',
    content: 'simal-content',
    textContainer: 'simal-text-container',
    htmlContainer: 'simal-html-container',
    validationMessage: 'simal-validation-message',
    actions: 'simal-actions',
    button: 'simal-button',
    confirmButton: 'simal-confirm-button',
    cancelButton: 'simal-cancel-button',
    denyButton: 'simal-deny-button',
    htmlInputs: 'simal-input',
    htmlFormInputs: 'simal-input'
}
API

Lifecycle and public methods.

Lifecycle

preOpen(dialog)Before the dialog opens.
didOpen(dialog)After showModal().
preClose(dialog)When closing begins.
didClose(dialog)After close and cleanup.

Methods

simal.fire()Open a dialog and receive a Promise.
simal.close()Close the active dialog.
simal.isVisible()Check whether Simal is visible.
simal.showValidationMessage()Display a validation message.
simal.getIcon()Get built-in icon HTML.

}
